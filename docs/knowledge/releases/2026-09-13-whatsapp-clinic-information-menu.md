# WhatsApp Clinic Information Menu — 13 September 2026

## What changed

The WhatsApp welcome menu no longer shows Quick booking. It now offers:

1. Choose appointment
2. My bookings
3. Last visit / prescription
4. Repeat last appointment, where a returning patient is eligible
5. Doctor directory & brochure
6. Clinic timings & location
7. Speak to front desk
9. Human assistance

## Information boundaries

- The doctor directory brochure is a public PDF generated from the same public booking catalogue: publicly listed doctors, clinic locations and recorded contact details only.
- The timing reply uses active schedule rules as reference information. Appointment availability is confirmed only within the live booking flow.
- The front-desk reply uses the clinic's recorded primary number, then an active location number if a primary number is not recorded.
- None of these information actions create a booking, collect clinical details or change consent.
